隱私權政策

你的進度，由你掌握。Google Drive 是由你選擇啟用的備份功能。

生效日期／最後更新：2026 年 10 月 13 日

本政策適用於 OuoukoDayo（由 promise82114 維護）的入口網站，以及本站連結的 EDF WB2 收集手帳（edfwb2-checklist）之 Google Drive 備份與還原功能。其他專案若有不同的資料處理方式，將另行說明。

本站不需要建立帳號。未啟用 Google Drive 時，收集手帳的進度保存在你的瀏覽器；啟用後，進度直接在瀏覽器與 Google Drive 之間傳輸，沒有由維護者營運的資料接收伺服器。

1. 我們存取哪些資料

  • 本機進度與設定：已取得項目、關卡收藏、啟用的遊戲內容、資料版本、更新時間，以及供復原使用的本機快照。這些資料由收集手帳保存在瀏覽器本機儲存空間。
  • Google Drive 應用程式資料：你授權後，應用程式讀取、建立或更新自己的進度 JSON 檔案（目前為 edfwb2-checklist.json），以及該檔案的 ID、名稱、版本和修改時間等必要中繼資料。
  • 授權資料：Google 提供的短期 OAuth Access Token、權限範圍與到期資訊，只用來呼叫 Drive API。應用程式不接收你的 Google 密碼，也不要求姓名、Email、聯絡人或 Gmail 存取權限。

Google Drive 的權限範圍為 https://www.googleapis.com/auth/drive.appdata。資料放在隱藏的 appDataFolder；此權限不允許瀏覽你的「我的雲端硬碟」一般檔案，也不存取其他應用程式的資料。同一 OAuth 應用程式的其他專案可能共用此應用程式資料空間，各專案以獨立檔名及 projectId 區分。

2. 資料使用目的

資料僅用於顯示和保存收集進度、備份、下載比較，以及由你選擇的合併或還原。首次連接只讀取雲端進度供比較；上傳與套用進度需由你在介面中明確操作。這不是持續在背景運作的即時同步。

我們不販售 Google 使用者資料、不將其用於廣告或信用評估，也不將其用於訓練通用 AI／機器學習模型。維護者不透過此功能取得或閱覽你的進度檔案。

3. Google API 資料的 Limited Use 承諾

OuoukoDayo 對從 Google API 取得之資訊的使用與傳輸，遵守 Google API Services User Data Policy 與 Google Workspace API User Data and Developer Policy，包括 Limited Use（有限使用）要求。

OuoukoDayo's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy and the Google Workspace API User Data and Developer Policy, including the Limited Use requirements.

4. 傳輸、第三方與網站紀錄

Google 登入和授權由 Google Identity Services 處理，進度由瀏覽器透過 HTTPS 直接傳送至 Google Drive API。Google 對其服務處理的資料依 Google 隱私權政策 管理；我們不將 Drive 進度傳送至其他分析、廣告或資料經紀服務。

入口網站與政策頁沒有加入分析追蹤工具、廣告程式或追蹤 Cookie。網站由 GitHub Pages 提供；GitHub 可能為安全與營運目的記錄訪客 IP 位址等請求資料，依其 隱私權聲明 處理。

如果你主動以 Email 聯絡我們，我們會收到你提供的 Email 與訊息內容，僅用於回覆、處理問題和必要的往來紀錄。請不要寄送 Access Token 或不必要的個人資料。若使用 GitHub Issues，留言可能公開顯示。

5. 保存與安全

  • Access Token 只保存在目前頁面的記憶體，不寫入 localStorage、sessionStorage、備份檔或 URL。重新整理、關閉頁面、中斷連接或到期後，需重新授權才能繼續存取 Drive。
  • 本機進度與快照保留至你移除相關瀏覽器資料；下載的 JSON 備份由你自行保管。
  • 雲端進度保存於你的 Google Drive，直到你刪除應用程式資料。中斷連接或撤銷權限不會自動刪除已儲存的進度。
  • 我們不在維護者伺服器保存 Drive 進度或 Token。裝置與 Google 帳號的安全，以及備份檔的保管，仍請由你妥善管理。

6. 撤銷授權、刪除與資料控制

  1. 中斷目前頁面：使用收集手帳的「中斷連接」清除此頁的 Token，兩端進度仍保留。
  2. 撤銷 Google 授權：前往 Google 帳號的第三方連結管理，移除 OuoukoDayo 對應應用程式的存取權限。這可能同時影響使用相同 OAuth 應用程式的其他專案。
  3. 刪除雲端進度：在 Google Drive 網頁的「設定 → 管理應用程式」中找到對應應用程式，透過其選項刪除隱藏的應用程式資料。這可能移除同一應用程式的其他專案備份，請先匯出需要保留的資料。
  4. 刪除本機資料：清除瀏覽器對本站的網站資料／本機儲存。本站專案共用網域，此操作可能清除其他專案的進度，請先匯出備份。已下載的 JSON 檔須另行刪除。

你可以不連接 Google Drive，繼續使用本機進度與 JSON 匯出。若希望刪除主動寄給我們的聯絡內容，或需要上述操作的協助，請透過下方 Email 聯絡。維護者無法直接替你操作私人 Drive 或裝置中的資料。

7. 政策更新與聯絡

資料處理方式變更時，我們會更新此頁與更新日期；新增需要 Google 權限的功能，會在使用前說明並要求相應授權。
